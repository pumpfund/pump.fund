## 🌀 How It Works

* **01 / ACCUMULATE:** Buy and hold `$PUMPFUND`. The Meteora pool automatically stacks a **5% LP trading fee** in wSOL on every buy and sell.


* **02 / SCAN:** A script live-scans pools every 5 minutes using an algorithmic formula (35% Log Volume / 65% Buy Velocity) to find the most active coin.


* **03 / SWEEP:** Every 10 minutes, the script claims the accumulated wSOL fees and swaps 100% of them into that trending coin via Jupiter.


* **04 / DROP:** An on-chain snapshot triggers instantly, and the bought tokens are airdropped directly to your wallet proportional to your holdings. No manual claims, no staking.
